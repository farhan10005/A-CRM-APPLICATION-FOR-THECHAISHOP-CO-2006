 TheChaiShop&Co CRM Application

Salesforce-based CRM project for TheChaiShop&Co, adapted from the **AI-ML-and-GEN-AI-Track-Project-Template** structure and implemented from the supplied project specification.

 Project Goal

Centralize customer, employer and enterprise records; automate sales/order calculations; validate business data; send birthday offers; and provide reports and dashboards for decision-making.

 Core Features

- Customer, Employer Account and Enterprise Account custom objects
- Online Order and Walk-In Order customer record types
- Global picklists for Gender, Items, Payment Mode and Type of Items
- Formula fields for Order Quantity and Total Bill
- Validation rules for Aadhaar and phone data
- Employer lookup relationships
- Scheduled birthday email automation
- Customer and Enterprise sales reports
- Customer vs Enterprise Sales dashboard
- Salesforce role/profile and permission-set based access

Technology Stack

| Layer | Technology |
|---|---|
| UI | Salesforce Lightning |
| Platform / Backend | Salesforce Platform |
| Database | Salesforce Cloud |
| Automation | Salesforce Flow |
| Analytics | Salesforce Reports & Dashboards |

 Salesforce Setup

1. Create a Salesforce Developer Org.
2. Deploy or recreate the metadata under `force-app/main/default`.
3. Configure custom objects, fields, global value sets, page layouts and record types.
4. Activate the birthday flow after configuring the email template and alert.
5. Create the reports and dashboard described in the documentation.
