# &#x20;Project Design Phase

## Problem-Solution Fit

The CRM replaces manual records with centralized Salesforce data, automated calculations, validation, workflow/Flow automation and real-time analytics.

## Main Components

1. User authentication
2. Customer Account management
3. Employer Account management
4. Enterprise Account management
5. Order and product capture
6. Formula-based order quantity and total bill
7. Validation rules
8. Online/Walk-In record types and page layouts
9. Birthday email automation
10. Reports and dashboard

## Architecture

* Presentation Layer: Lightning UI
* Application Layer: Flows and logic
* Data Layer: Custom Objects
* Analytics Layer: Reports and Dashboards
